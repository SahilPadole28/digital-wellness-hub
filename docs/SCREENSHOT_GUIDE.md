# Screenshot Capture Guide
**For student guide authors — Digital Wellness Resource Hub**

---

## 1. Before you start

Screenshots must show only the UI being demonstrated — **no personal data**.

---

## 2. Privacy-safe screenshot checklist

Before capturing any screenshot, check every item:

- [ ] **Notifications cleared** — no message previews, badge counts, or notification banners visible
- [ ] **Account name/email hidden** — sign out of accounts or blur/crop if visible
- [ ] **Photos hidden** — no personal photos in gallery, backgrounds, or avatars
- [ ] **Contact names hidden** — no real names in contact lists, message threads, or call history
- [ ] **Device identifier hidden** — no device name visible that could identify you
- [ ] **Other apps minimised** — no personal app data visible in app switcher
- [ ] **Status bar cleaned** — consider hiding: carrier name (can identify location), low battery, specific time
- [ ] **No real personal data** — no student ID, university name, actual daily usage stats

---

## 3. How to capture

### iPhone / iPad
1. Navigate to the exact screen you need
2. Clear all notifications (swipe them away)
3. Press **Side Button + Volume Up** simultaneously (iPhone X and later)
4. Find screenshot in Photos → export and crop as needed
5. Transfer to your computer and save to `/public/screenshots/<guide-id>/<step-file>.png`

### Android
1. Navigate to the exact screen
2. Clear notifications by swiping the notification shade
3. Press **Power + Volume Down** simultaneously
4. Find in Gallery / Photos app
5. Transfer and save to `/public/screenshots/<guide-id>/<step-file>.png`

### Windows (for f.lux guide)
1. Use **Win + Shift + S** (Snipping Tool) to capture a region
2. Or press **Print Screen** and paste into Paint → crop
3. Save as PNG

### Browser extensions (for algorithmic-cues guide)
1. Open an incognito/private window (no saved login state)
2. If logged in, ensure no name, photo or personal posts are visible
3. Use browser's built-in screenshot tool or an extension
4. Crop tightly to the UI element being demonstrated

## 5. Alt text verification

Each screenshot slot has a verified `screenshotAlt` in `src/data/guides.ts`. When replacing an image with your own capture, make sure the alt text still accurately describes the new image. If your interface differs (e.g. Samsung One UI instead of Pixel Android), update `screenshotAlt` in `src/data/guides.ts` accordingly.
