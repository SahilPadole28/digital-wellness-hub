# Student Needs Discussion Template — R1 Compliance
**Digital Wellness Resource Hub · Project 3**

This template satisfies R1: "Define a student audience and its main needs via a brief discussion/feedback activity."

---

## Purpose

Gather real student input about digital wellness challenges before (or early in) building the hub,
so the resource selection and tool descriptions are grounded in actual student needs — not assumptions.

---

## Activity: 15-Minute Group Discussion

**Who:** 5–10 fellow students (can be the same students you will later usability-test with, or a different group)
**When:** Before or alongside building the hub
**Format:** Structured discussion or anonymous written responses
